#sqlserver  

sometimes your system is not that complicated to need a DB, so you only work with *files* 

there are two types of those **txt** files 
- Delimited File 
	separates data with commas, 

- Fixed width size
	each date would get a *fixed*  byte size 

-- we haven't touched on the pros of file based system, if any 
# Drawbacks 

1. Bad Search 
2. Low Performance 
3. DB Redundancy 
4. Security, it's a text file after all 
5. No constraints 
6. No Data Quality (like inserting a string instead of a number)
7. Lack of a known standard

due to all this, the [[1.5 DB system]] has appeared
